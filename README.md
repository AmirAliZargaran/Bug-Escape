# Bug Scape

A 2D action/platformer game currently under active development, built with the **Unity Engine**.

---

## 📌 Project Overview & Current State
The project is in its early stages of development. The primary focus so far has been setting up the core gameplay feel and character responsiveness:
- **Core Player Mechanics:** Responsive 2D player controller with movement, jumping, and dash mechanics.
- **Character Animations:** State-machine animations for idle, run, jump, and dash states are fully integrated.

> [!NOTE]
> **Codebase Notice:** At this kickoff stage, some foundational scripts were adapted from my previous project (*Pixel Adventure*). As development progresses, these scripts will be refactored, cleaned up, and tailored specifically to this game's needs. As a result, you may encounter temporary or unused legacy scripts in the repository.

---

## 🎮 Controls
| Action | Key / Input |
| :--- | :--- |
| **Move Left / Right** | `A` / `D` or `Arrow Keys` |
| **Jump** | `Space` |
| **Dash** | `Shift` (or designated dash key) |

## 🎨 Art & Assets Notice
- **Sprites & Visuals:** All character and environment sprites currently in use have been generated using AI tools.
- Future tilesets and world assets will also be generated via AI, which are then manually curated, sliced, and assembled into functional 2D Tilemaps.
